# Map data

- `world_countries.geojson` is derived from Natural Earth and is in the public domain.
- `thailand_provinces.geojson` comes from `DevelopedbyWill/thailand-canonical-admin-names` and is licensed under CC BY 4.0. Its boundary data traces to OCHA/HDX Thailand administrative boundaries.
- Leaflet 1.9.4 is distributed under the BSD 2-Clause license.

The dashboard renders these local vector files directly. It does not request raster map tiles or require a map API key.
